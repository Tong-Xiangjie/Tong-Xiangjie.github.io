红框各一块，黑框跟着红框走。

## 关键间隙（用户要求「小一点」的那两处）

```
红框外缘 → 黑框外缘（上下）   = 2.79   (83.36→86.15 / 107.79→105.00 口径见下)
答题区提示 → 黑框外缘        = 1.36   (22.35 → 23.71)
答题区提示 → 红框外缘        = 4.78   (17.57 → 22.35)
```

当前网站的对应值：**1.996**（提示→黑框，用户要压到 0.5 左右）。
