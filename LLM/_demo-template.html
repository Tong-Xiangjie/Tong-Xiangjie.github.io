4 · 关于这一版

模型结构就是标准的 pre-LN 解码器：E[token] + P[pos] → 若干层「LayerNorm → 因果自注意力 → 残差 → LayerNorm → 前馈 → 残差」→ LayerNorm → 输出投影。 和常见实现唯一的区别是：这里的反向传播是手写的，没有用自动微分框架， 所以每一个中间梯度都要自己推、自己验。

详细的版本沿革、原先那几个"不报错但让模型学不动"的梯度 bug、 以及怎么用一份独立实现的 autodiff 逐参数块对拍把它抓出来，都写在 LLM/README.md 里。本页只做演示，不放那些内容。

诚实的局限：语料只有一万多字，参数量几万，纯 JS 单线程——它能学会常用搭配和短句结构， 学不会真正的语义。生成结果里有重复和语病是正常的，这不是 bug。
