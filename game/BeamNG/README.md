# 撞不坏 · 软体车辆物理沙盒

浏览器里的 BeamNG 风格车辆物理沙盒。整车不是一块刚体，而是 **304 个质点 + 1330 根梁** 组成的软体结构：撞墙时车头会真的折叠、溃缩、塑性变形，悬挂是每个车轮一根独立的自由度，轮胎用 Pacejka 魔术公式实时算力，发动机—离合器—变速箱—差速器整条传动链都在解算。

纯静态页面，不需要服务器、不需要构建、不需要联网（three.js 已经内联在 `vendor/`）。

## 怎么跑

```bash
# 方式一：直接双击 index.html
#   注意：file:// 下浏览器会以 CORS 为由拒绝加载 ES module（页面画得出来、
#   但按钮全是死的）。所以 index.html 检测到 file:// 会自动跳到自包含的
#   dist/BeamNG-single.html —— 它的模块用 data:URL 内联，双击就能玩。
# 方式二：起一个静态服务器（推荐，能跑多文件版，缓存/范围请求都正常）
node tools/serve.mjs 8811
#       然后打开 http://127.0.0.1:8811/index.html
```

线上地址：<https://tong-xiangjie.github.io/game/BeamNG/>（Pages 直接跑多文件版）。

URL 参数可以跳过菜单直接进游戏，方便截图和分享：

```
index.html?autostart=1&preset=sports&mode=crash&quality=high
```

`preset` = `sedan | sports | pickup | hatch`，`mode` = `free | crash | drag | track`，`quality` = `low | medium | high | ultra`。

### 单文件版

```bash
node tools/build-single.mjs          # → dist/BeamNG-single.html（约 1.3 MB，完全自包含）
```

它把 23 个 ES 模块分别编码成 `data:` URL 并用 import map 串起来——不是粗暴拼接，所以模块作用域和原来完全一致。单文件版双击即玩，方便丢给别人的电脑或者塞进 U 盘。

## 物理是怎么搭的

### 1. 软体车身（`js/phys/softbody.js`）

车身是一个"环形截面 + 纵向站位"的管状点阵：

- **12 点环截面**：`floorC / floorR / sillR / shoulderR / glassR / roofR / roofC / roofL / glassL / shoulderL / sillL / floorL`，左右严格镜像。
- 沿车长方向若干**站位**（前防撞梁、机舱、A 柱、车门、B 柱、C 柱、后防撞梁……），把相邻环用梁连起来，再加上纵向长梁、交叉斜撑、地板/车顶的三角化，一共 1330 根梁。
- 每根梁带自己的 **zone 强度**：`crush`（溃缩区，软）→ `engine` → `cabin`（乘员舱，最硬）→ `deck`。所以正面撞击时是车头一节一节吃能量，乘员舱基本不变形。

求解器是 **基于位置的动力学（PBD）**：每个子步先积分速度、再迭代投影距离约束（Gauss–Seidel；物理模块默认 10 次，游戏内按画质档位 8 / 10 / 13 / 16），最后回写速度。固定步长 1/300 s、每帧 4 个子步，掉帧时最多追赶 3 帧。核心循环里没有任何对象分配——所有状态都是 `Float64Array` 的 SoA 布局，一帧跑完 GC 一动不动。

**塑性流动**：梁的应变超过屈服阈值后，它的"静止长度"会被真的改写短一点点（`rest` 变小），并且**永不回弹**。这就是车头被撞瘪之后不会自己弹回来的原因。同时记录每根梁被压短的量，用来算车损百分比。

**断梁**：应变再往上越过断裂阈值，梁直接标记 `BROKEN`、从约束列表里摘掉，车头就开始"散架"——翼子板外翻、保险杠挂下来、车轮失去支撑。

断裂阈值不是拍脑袋定的，是量出来的。踩坑记录：一开始溃缩区写的是 0.55，但塑性流动每步都在把静止长度往当前长度推，应变会被**一直压在 2% 上下**——阈值 0.55 等于永远断不了。实测每根刚体梁的历史峰值应变：

| | ring | long | diag | 塔顶焊点 |
| --- | --- | --- | --- | --- |
| 日常驾驶（急加速/绕桩/急刹） | 0.065 | 0.064 | 0.037 | 0.009 |
| 50 km/h 撞墙 | 0.288 | 0.343 | 0.292 | 0.053 |
| 100 km/h 撞墙 | 0.501 | 0.305 | 0.299 | 0.099 |
| 140 km/h 撞墙 | 0.633 | 0.388 | 0.317 | 0.122 |

于是阈值取在 0.14~0.28 这一带（日常驾驶留 2~4 倍余量，撞车必然撕开），塔顶那几根"焊点"单独调软到 0.032——它们是刻意设计的薄弱环节。

**掉轮**：吊住车轮的是"塔顶 → 车身/摆臂"那 5 根梁，断掉一半以上轮子就飞出去。原来的判据是"所有碰到塔顶节点的梁存活 < 3"，前轮那种一共 25 根，等于要求断 23 根，实测 180 km/h 也做不到；改成只看那 5 根之后，180 km/h 正面撞墙会掉两个前轮。

### 2. 地形与静态物（`js/phys/terrain.js`、`statics.js`、`world.js`）

- 地形是**解析式**的：多层 fbm 噪声 + 平坦区 + 道路整平 + 场坪 + 远景山脉，`height(x,z)` / `normal(x,z)` / `materialAt(x,z)` 三个函数就够了，物理和渲染共用同一份定义，永远不会出现"看到的和踩到的不一样"。
- 7 种地表材质各有自己的摩擦系数与滚阻：沥青 1.00、混凝土 0.92、碎石 0.70、泥土 0.62、草地 0.55、沙地 0.45、泥浆 0.34。
- 地形查询走 **0.5 m 网格缓存 + 双线性插值**（`heightFast`）：解析求值一次要 2.3 µs，物理一帧要问几万次，缓存后单次几十纳秒，误差 0.2 mm（最大 1.8 mm）。这一项就让整个物理帧从 7.4 ms 掉到 2.5 ms。
- 静态物（护栏、集装箱、斜坡、锥桶、电线杆、树、混凝土墙）统一是**有向包围盒 / 圆柱**，放在均匀网格里做粗筛选；球体求交后把接触面写成**切线平面**缓存（步长 5 的 `[nx,ny,nz,depth,materialId]`），软体求解器直接消费。

### 3. 悬挂 / 轮胎 / 传动（`js/vehicle/`）

- **悬挂**：每个车轮一根沿减振器轴线的 1 自由度弹簧-阻尼，上下硬点是真的车身节点，所以撞歪了塔顶会直接影响车轮定位。
- **轮胎**：胎面按 5 个角度采样，法向力考虑胎压与下沉量，纵向/侧向力用带载荷敏感性的 **Pacejka 魔术公式**；还带松弛长度（力的建立有延迟）、摩擦椭圆（纵向和侧向共享附着）、以及转动惯量反射（发动机的等效惯量会通过传动比压到驱动轮上，所以低挡收油会有拖拽感）。
- **传动**：发动机是带惯量的转速-扭矩曲线 + 怠速控制 + 红线断油；离合器有容量、刚度、阻尼，能半联动；变速箱有 6 个挡位和换挡时间；差速器分前后驱并分配扭矩。ABS 与 TC 都实现了（轮速骤降/驱动轮打滑时介入）。
- **气动**：迎风阻力 + 前后升力（含气动中心高度，所以高速会自己抬头/低头）。

### 4. 车损统计（`Vehicle.deformStats`）

量车损的难点在于"跟谁比"。用整车重心/前悬硬点当参考，车头一压溃它们就跟着跑，会把整台车都算成形变（100 km/h 撞墙能读出 1 米多的"压溃"）。现在的做法是：

- 用**车尾 25% 的节点**当锚点，再用后半部的顶/底节点定姿态基准，建立一个"车尾锚定的参考坐标系"；
- 把出厂形状表达在这个坐标系里，只有当车辆静止且还没真的撞坏时，才让参考形状慢慢跟踪当前形状（吸收自重引起的弹性下沉）；
- 一旦某根梁被压短超过 2 cm（真的撞出坑了），参考形状就**冻结**，之后量到的全是永久压溃。

最终读数：受损区域的**平均压溃深度**、98 分位的**最深压溃**、受损节点占比、完好度、断梁率、掉轮数，加权成 0~100% 的综合车损。崭新的车停在原地读 0.0%，100 km/h 撞墙读 76%。

## 已知取舍

- 慢速沉降时车身会残留约 3° 的横滚（无侧向力输入），静止时的四轮载荷有约 ±5% 的不对称——PBD 的迭代次数和梁的刚度分布决定的，不影响驾驶手感。
- 100 km/h 撞墙时最大溃缩量会到 1.6 m（98 分位），比真车（约 70 cm）略深——梁的断裂阈值为了让"日常驾驶绝不断裂"留了余量，代价是重撞下比真车稍微"软"一点。140 km/h 以上 98 分位会顶到直方图上限（2.0 m）而饱和，那个区间里车损百分比靠断梁率和平均压溃区分（78% → 97%，仍单调）。
- 物理跑 4 个子步固定 1/300 s，浏览器掉到 20 fps 以下时会靠最多 3 帧追赶，再慢就开始"慢动作"（这是刻意的，宁可慢动作也不要数值爆炸）。
- 没有做车型级的 NVH：发动机是合成音，不是采样。
